# HTML 结构预览编辑工具

一个纯前端的单文件 HTML 工具，双击 `index.html` 即可使用，无需安装、无需后端、无任何外部依赖。

## 功能特性

- 📂 **导入 HTML**：支持点击选择文件、拖拽上传、粘贴 HTML 文本，或从 URL 导入。
- 🌳 **DOM 树形视图**：基于浏览器原生 `DOMParser`（`text/html` 模式）容错解析，结构化展示为可按层级展开/折叠的树：
  - 点击任意元素行就地折叠或展开；
  - 单击选中元素，双击可编辑该元素的 `outerHTML`；保存后结构树、渲染预览、复制和下载源码同步更新；
  - 工具栏一键「展开 / 折叠」；
  - 按层级展开：仅根、1 层、2 层、3 层。
- 🏷️ **完整 HTML 语义**：
  - DOCTYPE 灰字节点；
  - 元素、属性、文本、注释均有着色展示；
  - `id` / `class` 属性值单独高亮；
  - void 元素（如 `<meta>`、`<img>`、`<br>` 等）无闭合标签展示；
  - `script` / `style` 内容截断预览，并标注字符长度。
- 🧹 **精简模式**（默认开启）：隐藏 `style` 属性值（显示 `style="…"`）与 `script` / `style` 内容，只看结构。
- 👁️ **渲染预览与对比**：在工具栏切换三种视图——
  - **结构**：默认的 DOM 树形视图；
  - **渲染**：用沙箱 iframe 还原 HTML 的真实视觉效果（CSS 生效）；
  - **对比**：左侧结构树 + 右侧渲染效果左右并排，便于对照查看。
  > 可直接点击预览中的文字修改内容，复制和下载的源码会自动同步；预览中的脚本仍被禁用、不会执行，点击「刷新」可重新渲染。
- 📋 **所有文本字段均可复制**（鼠标悬停显示按钮）：
  - 复制**标签名**（点击标签）、**属性名 / 属性值**（点击属性）；
  - 复制**文本内容**（点击文本）；
  - 复制元素的 **XPath 路径**（如 `/html/body/main/article[1]/h2`）；
  - 复制整个节点的 **outerHTML**；
  - 一键**复制全部 HTML**。
- 🎨 语法着色（标签 / 属性 / 文本 / 注释 / DOCTYPE）；粘贴和元素源码编辑框支持实时 HTML 高亮、深浅色主题切换、自适应移动端。
- 📊 实时统计：文件大小、源码行数、元素节点数、最大深度。

## 使用方式

直接用浏览器打开 `index.html` 即可：

```bash
open index.html        # macOS
# 或拖入浏览器
```

点击「示例」可快速体验效果。

## 技术说明

- 单一 HTML 文件，原生 HTML / CSS / JavaScript，零依赖、零构建步骤。
- 所有解析与渲染均在浏览器本地完成，不上传任何数据。
- 用户输入仅做解析与展示，不会通过 `innerHTML` 注入到页面 DOM，也不会执行 `script` 内容。
- 渲染预览运行在脚本禁用的沙箱 iframe 内：仅授予父页面读取预览 DOM 的同源权限，以便同步用户编辑的文字；脚本不执行、表单不提交。
